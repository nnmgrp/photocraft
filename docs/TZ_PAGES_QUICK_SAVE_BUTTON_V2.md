## 1. Цель

Добавить в панель «Страницы» кнопку `💾`, которая **в один клик сохраняет изменённую страницу в её существующий файл на диске, без диалогов и без Save As**.

Кнопка нужна только там, где обещание «сохранить сразу» выполнимо:

- страница действительно изменена (`is_dirty`);
- у страницы есть путь на диске;
- формат умеет хранить документ целиком и сохраняться на месте: **PSD, PSB, `.pcraft`, ORA**;
- для ORA — только если в неё помещается всё содержимое (`holds_at`), иначе сохранение потеряло бы слои/стили/маски.

Для плоских форматов (PNG, JPEG, TIFF, WebP, TGA и т.п.), безымянных документов и «непомещающейся» ORA кнопки быть не должно. Save As остаётся доступен через закрытие страницы, `Ctrl+S` и меню File.

## 2. Пользовательский сценарий

1. В главе открыто 20 страниц. Пользователь правит страницу 7, затем переходит на страницу 12.
2. Страница 7 остаётся «грязной»; в панели Pages у неё появляется `💾`.
3. Пользователь нажимает `💾` у страницы 7:
   - страница 7 становится активной (как если бы по ней кликнули);
   - её документ записывается в свой PSD/PSB/`.pcraft`/ORA;
   - никаких окон Save As, форматов и опций не появляется;
   - маркер «грязная» и кнопка `💾` исчезают;
   - страница 12 и остальные документы не меняются.
4. Если файл на диске был изменён другой программой, появляется **существующий** диалог «файл изменён»; при отмене страница остаётся грязной, кнопка остаётся.
5. Если сохранение не удалось (нет прав, диск, ошибка экспорта), появляется уведомление об ошибке; страница остаётся грязной, кнопка остаётся.

## 3. Термины и существующая логика

| Термин / функция | Значение |
|---|---|
| `is_dirty()` | В документе есть несохранённые изменения. |
| `saves_in_place(path)` | Расширение файла — `psd`, `psb`, `pcraft` или `ora` (регистр не важен). |
| `holds_at(doc, path)` | Формат может быть собственным файлом документа: PSD/PSB/`.pcraft` — всегда; ORA — только если `ora_losses(doc)` пуст. |
| `file.save` без `path` | Штатная команда: если `saves_in_place && holds_at`, пишет в текущий файл; иначе уходит в Save As. |
| `foreground_save(app)` | Текущее сохранение в foreground-режиме (Preferences › File Handling › Save in Background выключен). Пока оно идёт, приложение блокирует команды над документами. |

**Важно:** кнопка не должна сама решать, «как сохранять». Она вызывает только `file.save` с пустыми параметрами. Но перед вызовом она обязана повторно проверить, что страница всё ещё сохраняется на месте. Иначе устаревшая кнопка может провалиться в Save As, что противоречит обещанию «просто сохранить».

## 4. Матрица форматов и состояний

| Ситуация | Путь | `saves_in_place` | `holds_at` | `💾` | Причина |
|---|---|---:|---:|---:|---|
| Грязный PSD | есть | да | да | **да** | Пишется на месте. |
| Грязный PSB | есть | да | да | **да** | Пишется на месте. |
| Грязный `.pcraft` | есть | да | да | **да** | Нативный формат. |
| Грязная ORA без потерь | есть | да | да | **да** | ORA хранит всё содержимое. |
| Грязная ORA с adjustment layers / styles / masks и т.п. | есть | да | **нет** | **нет** | Сохранение потеряет данные; нужен Save As. |
| Грязный PNG / JPEG / TIFF / WebP / TGA / GIF / BMP / PDF | есть | **нет** | — | **нет** | Плоский формат; Save As. |
| Безымянный / новый документ | нет | — | — | **нет** | Нечего перезаписывать. |
| Чистая страница | есть | — | — | **нет** | Сохранять нечего; маркер `is_dirty` уже показывает состояние. |
| Шаблон `.psdt` открыт | нет | — | — | **нет** | Шаблон открывается как безымянный документ. |
| Файл только для чтения | есть | да | да | **да** | Кнопка обещает сохранение; ошибка прав показывается уведомлением, страница остаётся грязной. |
| Файл удалён/перемещён снаружи | есть | да | да | **да** | `file.save` сообщит об ошибке; грязность сохраняется. |
| Идёт foreground save | — | — | — | **нет (скрыта у всех)** | Нельзя запустить второе сохранение. |

Расширения проверяются без учёта регистра: `.PSD`, `.Psb`, `.ORA` допустимы. Путь без расширения или скрытый файл без расширения — не сохраняется на месте.

## 5. Точный предикат

### 5.1. Допустимость (eligibility)

```text
is_dirty
&& path.is_some()
&& saves_in_place(path)
&& holds_at(doc, path)
```

Это чистая функция от документа, пути и флага грязности. Она используется и для показа кнопки, и для повторной проверки в обработчике.

### 5.2. Текущая видимость

```text
show_quick_save =
    eligibility
    && foreground_save(app).is_none()
```

Пока идёт foreground save, кнопки `💾` скрываются у всех страниц. Это сознательное решение: так невозможно дважды нажать сохранение и не нужно отдельное «disabled»-состояние, которое всё равно нужно проверять в обработчике. После завершения сохранения кнопки возвращаются у тех страниц, которые всё ещё грязные.

### 5.3. Почему не `can_save`/`can_write`

Не нужно проверять права доступа, свободное место и блокировки файла заранее. Это дало бы ложные «нельзя» и рассинхрон с реальным сохранением. Ошибка записи обрабатывается существующим механизмом уведомлений, а страница остаётся грязной. Проверяются только формат и полнота документа.

## 6. UI

### 6.1. Список (List View)

В правой группе кнопок порядок в `Layout::right_to_left`:

```text
✖  →  💾  →  ↓  →  ↑
```

Визуально слева направо:

```text
[↑] [↓] [💾] [✖]
```

- `💾` показывается только при `item.can_quick_save`.
- Размер — тот же `small_button`, что у `✖`; не больше и не «плавающий».
- Подсказка: **«Сохранить страницу в её файл»**. Без `(Ctrl+S)` в тексте, чтобы не обещать неверную комбинацию на macOS; сочетание и так видно в меню File.
- Кнопка не должна сдвигать строку `Стр. X` при появлении/исчезновении: раскладка `right_to_left` это обеспечивает.
- Клик по `💾` не должен одновременно активировать карточку: существующая проверка `if response.clicked() && action.is_none()` сохраняется, а кнопка выставляет `action = Some(SavePage(..))`.

### 6.2. Сетка (Grid View)

В нижней строке карточки, в `Layout::right_to_left`:

```text
✖  →  💾
```

Визуально:

```text
[💾] [✖]
```

Показывается только при `item.can_quick_save`; подсказка та же. В сетке нет кнопок ↑/↓, поэтому пара `💾 ✖` стоит справа.

### 6.3. Контекстное меню

Порядок пунктов:

1. Существующие пункты переименования/перемещения (как сейчас).
2. `separator`
3. `📂 Показать в проводнике`
4. `separator`
5. **`💾 Сохранить страницу`** — только если `item.can_quick_save`; обычный цвет текста, без зелёного.
6. `✖ Закрыть страницу` — красный, как сейчас.

После клика — `ui.close()`. Пункт не показывается disabled у всех страниц: он либо есть, либо его нет.

### 6.4. Индикатор грязности

Не меняется: `●` в списке и точка/`*` в сетке уже показывают несохранённые изменения. `💾` — это действие, а не замена индикатору.

## 7. Поведение при клике

### 7.1. Действие

Добавляется вариант:

```rust
PagesPanelAction::SavePage(usize)
```

Индекс — тот же `doc_index`, что у `ClosePage`. Путь и `DocId` в действие не кладём: обработчик берёт актуальный документ по индексу и заново проверяет его состояние. Это защищает от устаревшей карточки между кадрами.

### 7.2. Алгоритм обработчика

1. Взять документ по `idx`. Если индекса нет — уведомление об ошибке, выйти. Никаких паник.
2. Если `foreground_save(self).is_some()` — выйти без второго сохранения. Допустимо показать нейтральное уведомление «Сохранение уже выполняется», но не ошибку.
3. Повторно проверить `can_quick_save_page(doc, path, is_dirty)`. Если `false` — уведомление об ошибке «Эту страницу нельзя сохранить на месте. Используйте „Сохранить как“», выйти. **Это ключевая защита от Save As из этой кнопки.**
4. Активировать страницу тем же путём, что и клик по карточке (см. 7.3). Если активация не удалась — уведомление, выйти.
5. Убедиться, что `session.active_index() == Some(idx)`. Если нет — уведомление, выйти.
6. Ещё раз проверить допустимость после активации (документ мог измениться). Если `false` — уведомление, выйти.
7. Вызвать `crate::menus::invoke(self, ctx, "file.save", json!({}))`.
8. При `Err` — уведомление об ошибке; **не** сбрасывать `is_dirty` вручную, **не** вызывать `save_as`, **не** писать через движок напрямую.
9. При успехе документ сам снимает `is_dirty`; на следующем кадре кнопка исчезает.

### 7.3. Активация страницы

Сейчас ветка `SelectPage` в `handle_pages_action` делает больше, чем `session.set_active(idx)`: при `pages.auto_sync_typer` она синхронизирует `typesetter.state.current_page` и `current_line_idx` по имени/пути документа. Если `SavePage` вызовет только `set_active`, поведение будет отличаться от клика по карточке.

Требуется вынести общую функцию:

```text
fn activate_page(&mut self, idx: usize) -> bool
```

- `session.set_active(idx)`; `false`, если индекс невалиден.
- Тот же блок `auto_sync_typer`, что у `SelectPage`.
- Никаких `auto_save`, изменения документа или побочных эффектов.
- `SelectPage` и `SavePage` вызывают только её.

Это исправляет известный дефект текущей реализации GLM, где `SavePage` вызывал `set_active` напрямую.

### 7.4. Диалог «файл изменён другой программой»

Остаётся штатный диалог `file.save`. Кнопка не должна обходить его прямой записью. Если пользователь отменил диалог — страница остаётся грязной, кнопка остаётся.

### 7.5. Ошибки и уведомления

Панель Pages сейчас полностью на русском и не использует `tl!`; не добавляем один `tl!`-ключ в русскую панель. Тексты:

| Ситуация | Текст |
|---|---|
| Нет индекса | «Не удалось сохранить страницу» + «Страница больше не существует (индекс N).» |
| Устарела допустимость | «Эту страницу нельзя сохранить на месте. Используйте „Сохранить как“.» |
| Ошибка записи | «Не удалось сохранить страницу» + строка ошибки. |

Все — с `error = true`. Документ остаётся грязным; кнопка остаётся, если страница всё ещё допустима.

## 9. Тесты

### 9.1. Предикат

`quick_save_eligibility_matches_document_and_format`:

- PSD, PSB, `.pcraft`, ORA — `true` для грязного документа с путём.
- `None`, чистая страница, PNG/JPEG/WebP/TGA — `false`.
- ORA с adjustment layer — `false`; PSD с тем же документом — `true`.
- Расширения в верхнем регистре — `true`.
- Путь без расширения — `false`.

### 9.2. Действие

- `save_page_activates_and_saves_target_document`: два документа; документ 0 — грязный PSD с путём; активен 1; `SavePage(0)`; активен 0; документ 0 чистый; документ 1 не тронут; уведомлений нет.
- `save_page_reports_invalid_target_and_save_errors`: невалидный индекс и ошибка экспорта; уведомление `error`, грязность сохраняется, паники нет.
- `save_page_refuses_stale_ineligible_target`: после построения карточки поменять путь на `page.png` (или добавить adjustment layer в ORA); `SavePage(0)`; уведомление об ошибке, экспорт не вызван, грязность сохраняется. Это доказывает, что кнопка не уходит в Save As.
- `save_page_skips_when_foreground_save_runs`: если удаётся поднять foreground save job — `SavePage` не запускает второй экспорт. Если конструкция job слишком тяжёлая для юнит-теста, проверить общую функцию-гейт и добавить ручной пункт в чек-лист.
- `save_page_activation_syncs_typer_page`: `auto_sync_typer = true`; документы `page_007.psd` и `page_012.psd`; активен второй; `SavePage(0)`; `typesetter.state.current_page == 7`.

### 9.3. UI

Если панель Pages легко поднимается в kittest:

- две страницы: грязный PSD и чистая PNG;
- `💾` есть только у PSD;
- в списке и сетке прямоугольник `💾` левее `✖`;
- в контекстном меню пункт есть только у PSD и стоит перед закрытием.

Если панель не поднимается в kittest без больших костылей — не имитировать пиксельный тест, а добавить тест на предикат/`PageItemInfo` и ручной чек-лист. В ТЗ не должно быть «тестов», которых нет.

### 9.4. Регрессии

- Закрытие грязной страницы по-прежнему показывает discard prompt (существующий тест).
- `Ctrl+S`/File Save для плоского файла по-прежнему уходит в Save As.
- Контекстное меню «Закрыть страницу» работает.
- Нет новых предупреждений/clippy.

## 14. Итог

Кнопка `💾` — это не второй Save As, а честное «записать эту страницу в её файл». Она появляется только тогда, когда это технически возможно, активирует свою страницу, уважает внешние изменения и не запускает второе сохранение. Всё, что требует выбора формата или пути, остаётся за `✖`, `Ctrl+S` и меню File.
